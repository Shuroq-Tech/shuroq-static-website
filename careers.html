ML Internship

Internship
3 Months
Unpaid
Remote

About the Role

Join our Machine Learning team and gain hands-on experience in developing and implementing ML models for real-world applications. This internship offers the opportunity to work on cutting-edge AI projects and learn from industry experts.

Key Responsibilities

  • Assist in developing and training machine learning models
  • Work with data preprocessing and feature engineering
  • Collaborate with senior ML engineers on project implementation
  • Participate in model evaluation and optimization
  • Contribute to documentation and research activities

Requirements

  • Currently pursuing or recently completed degree in Computer Science, Data Science, or related field
  • Basic understanding of machine learning concepts and algorithms
  • Proficiency in Python and familiarity with ML libraries (scikit-learn, TensorFlow, or PyTorch)
  • Strong analytical and problem-solving skills
  • Eagerness to learn and work in a collaborative environment

What You'll Learn

  • Real-world ML project implementation
  • Industry best practices in model development
  • Collaboration in an agile development environment
  • Exposure to various ML domains and applications

DevOps Internship

Internship
3 Months
Unpaid
Remote

About the Role

Gain valuable experience in DevOps practices and tools by working with our infrastructure and deployment teams. This internship provides hands-on exposure to modern DevOps methodologies and cloud technologies.

Key Responsibilities

  • Assist in maintaining and improving CI/CD pipelines
  • Work with infrastructure as code (IaC) tools like Terraform
  • Support cloud infrastructure management on AWS/Azure
  • Participate in monitoring and logging implementation
  • Collaborate with development teams on deployment strategies

Requirements

  • Currently pursuing or recently completed degree in Computer Science, IT, or related field
  • Basic understanding of cloud platforms (AWS, Azure, or GCP)
  • Familiarity with Linux/Unix environments
  • Knowledge of scripting languages (Python, Bash, or PowerShell)
  • Interest in automation and infrastructure management

What You'll Learn

  • Enterprise DevOps practices and methodologies
  • Cloud infrastructure management
  • Containerization technologies (Docker, Kubernetes)
  • Monitoring and observability best practices
